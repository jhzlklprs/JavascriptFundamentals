# JavaScript Fundamentals

A structured collection of JavaScript fundamentals, examples, exercises, and practice code focused on building a strong foundation in JavaScript and modern frontend development.

This repository follows my personal JavaScript learning roadmap and tracks my progress from core language concepts to Svelte 5.

---

## 🎯 Learning Goal

Build a solid understanding of JavaScript fundamentals, then apply them to frontend development with HTML, CSS, and Svelte 5.

Coming from C# / .NET, the aim is to learn JavaScript by comparing it with concepts I already know (LINQ vs array methods, async/await in both, classes, generics vs TypeScript) and by understanding the language itself before relying on frameworks.
